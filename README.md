## Maintaining the site
The site is a single static file, `index.html`, served by GitHub Pages.

- **Photo:** add a headshot named `photo.jpg` to the repository root. Until then, an "NA" monogram is shown.
- **CV:** add `cv.pdf` to the repository root. The CV buttons and links stay hidden until the file exists.
- **Publications:** copy the commented template inside the *Publications & Manuscripts* section of `index.html`.
- **Scholar / ORCID:** uncomment the buttons in the hero section and fill in your IDs.
